Pertanyaan yang Sering Diajukan

Apakah pengunjung harus mendownload aplikasi terlebih dahulu? ▾
Sama sekali tidak! Ketika pengunjung menempelkan HP ke kartu meja Hitabels, browser bawaan (Safari di iPhone, Chrome di Android) langsung otomatis terbuka menampilkan hub meja kafe Anda.
Bagaimana jika HP pengunjung tidak memiliki sensor NFC? ▾
Setiap kartu meja Hitabels sudah dilengkapi dengan kode QR beresolusi tinggi di samping chip NFC. Jadi 100% semua jenis smartphone berkamera tetap bisa mengaksesnya dengan mudah.
Jika saya ganti password Wi-Fi atau mengubah harga menu, apakah harus ganti kartu? ▾
Tidak perlu ganti kartu! Anda cukup masuk ke Dashboard Admin Hitabels, ganti password Wi-Fi atau harga menu di sana, dan dalam hitungan detik semua kartu di meja sudah langsung otomatis terupdate.
Bagaimana proses pemesanannya? ▾
Cukup klik tombol "Pesan Sekarang" untuk terhubung dengan tim kami via WhatsApp. Kami akan meminta nama kafe, logo, serta daftar menu untuk disiapkan sebelum kartu dicetak dan dikirim ke alamat Anda.
